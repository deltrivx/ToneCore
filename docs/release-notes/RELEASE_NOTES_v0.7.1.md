# ToneCore v0.7.1

## 修复

- **音源「测试」按钮恒定失败** —— 真因是调用写错，不是音源问题：`Sources.vue` 里写成了 `api.sourceTest(s.file, 测试)`，**`测试` 是没加引号的裸标识符**，运行时抛 `ReferenceError: 测试 is not defined`，被 catch 吞成「测试失败」。于是每次点测试都失败；而状态区显示的是 `source-health.json` 的历史统计（可能仍是「正常/部分可用」），两处来源不同，观感就成了「点测试全失败、界面却显示有成功」。
  - 关键词改为常量 `TEST_KEYWORD = 稻香`（各平台都有的热门歌，测试才有真实信号）。
  - 异常不再笼统吞掉，透出 `e.message`。
  - 界面明确区分：状态区标注「历史」，测试结果标注「本次测试」。

## 变更

- **去掉主页重复展示**：原先同时有「专辑封面墙」和「曲目列表」，同一批歌展示两遍；现只保留单列曲目列表（每行带封面缩略图）。
- **两个搜索框语义厘清**：主页搜索框 = 只搜本地；曲库搜索框 = 只搜云端；移除曲库右上角本地小搜索框。
