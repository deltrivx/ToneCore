# ToneCore v0.13.0

设置页结构调整，并完整复刻 SongLoft MIoT 插件的音箱配置能力（前后端）。

### 新增

- **音箱高级配置区 `components/SpeakerConfig.vue`**：按分组渲染 SongLoft MIoT
  的全部可配置项 —— 语音指令（解析开关 / 上下文记忆 / 记忆条数 / 定时任务 / 时区）、
  播放与音质（强制 MP3 / 电台强制 MP3 / 音量归一化 / 切歌偏移）、
  选源策略（并发或顺序 / 单条指令取歌上限）、设备显示（指示灯 / 触屏歌词）、
  语音播报（搜索提示语 / 播放前播报模板与延迟 / 生效范围）、
  高级与 AI 兜底（智能续播超时 / 调试日志 / AI 接口地址与模型）。
- 后端 `SpeakerConfig` 扩展 27 个配置字段，`status` 全部回显供前端渲染。
- AI 密钥脱敏回显：`status` 只给 `aiApiKeySet` / `aiApiKeyHint`（尾部 4 位），
  真实密钥不下发到前端。

### 变更

- **设置页「关于」移到页面底部**：版本、目录、项目链接属于附属信息，
  放在主配置之后更符合预期；原先夹在「账号管理」与「小爱音箱接入」之间，
  打断了配置项的连续性。
- 播放前播报与搜索提示的补充字段改为**随开关联动显示**，关闭时不占位。

### 修复

- **AI 密钥被回显串覆盖**：`status` 回传的 `aiApiKeyHint` 形如 `…ca0f`，
  前端若把整个 status 原样回传会把提示串写进真实密钥位，直接打死 AI 兜底。
  `configure()` 现丢弃这两个非可写字段，且拒绝用「空串 / 提示串」覆盖已存密钥。
