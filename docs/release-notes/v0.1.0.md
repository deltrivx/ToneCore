# ToneCore v0.1.0

首个版本。ToneCore 是一个**无头音乐中枢** —— 不做播放器界面，只负责把「想听的歌」
送到小爱音箱，并在这个过程中把音源沉淀成本地曲库。

镜像：`ghcr.io/deltrivx/tonecore:0.1.0`（同时提供 amd64 与 arm64）

---

## 语音点歌

对音箱说「播放周杰伦的晴天」，链路自动完成：

1. 先查本地曲库，命中直接推流
2. 未命中则全网找音源，取无损直链
3. 推给音箱播放（**秒播，不等下载**）
4. 后台异步下载到本地，写好标签、封面、歌词
5. 下次再点这首歌，直接本地播放

指令解析同时支持播放控制与音量：上一首、下一首、暂停、继续、停止，
「音量调到 50」与「大声点」这类相对调节也认。这些能力在控制台的音箱设置里
同样可以手动下发，便于排查问题。

## 音源引擎

多平台并发搜索后**统一打分竞争**，而不是按固定平台顺序取第一个成功的。

这一点直接决定了会不会点错歌：同一个关键词在各平台的结果质量差异很大，
某些平台的搜索结果可能全是翻唱。引擎把各平台候选放在一起，
按标题相似度、歌手匹配度、版本噪音词（伴奏 / DJ / 翻唱 / 现场等）综合评分，
分数高的先取链；同时设有分数下限，宁可返回失败也不降级到「别的歌手的翻唱」。

内置酷我直连通道作为保底，不依赖第三方脚本；第三方脚本按健康度排序、
连续失败自动熔断。

## 无损落库与自动刮削

下载队列串行执行并保持固定间隔，降低触发风控的概率。
落盘前做音频魔数校验，确认下到的是音频而不是站点返回的 HTML 错误页。

落库完成后自动补齐元数据：

- 写入 ID3v2（MP3）或 Vorbis Comment（FLAC）标签
- 嵌入专辑封面
- 写入歌词，同时存进标签与同名 `.lrc` 文件

对已有曲库也支持批量补全 —— 早先手动放进去的文件同样能被补齐。

## 本地曲库

SQLite 索引，支持关键词检索、分页、试听与统计。
删除是移入回收站（`/data/_trash`）而非直接删除文件。

## 控制台

Vue 3 + Tailwind 深色界面，含总览 / 音源 / 曲库 / 设置四个页面，PC 与移动端适配。
音箱设备列表可直接试播语音、下发播放控制与调节音量。

## 部署

```bash
docker run -d \
  --name ToneCore \
  --restart unless-stopped \
  -p 8090:8090 \
  -e TZ=Asia/Shanghai \
  -v /your/music:/music \
  -v /your/appdata/tonecore:/data \
  ghcr.io/deltrivx/tonecore:0.1.0
```

打开 `http://<你的IP>:8090` 完成初始化：设置页确认落库策略与音质，
曲库页建立索引，音源页确认脚本已加载。

Unraid 用户可直接使用容器模板，模板内已预置端口、路径与环境变量。
