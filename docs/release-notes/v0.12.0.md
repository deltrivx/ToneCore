# ToneCore v0.12.0

从「科技风 demo 界面」重构为**成熟音乐平台的界面体系**：全站图标矢量统一、
导航单入口、配色与间距 token 化，并移除无用的视觉噪音与死代码。

### 新增

- **矢量图标体系 `components/Icon.vue`**：46 个内联 SVG，统一 24×24 视框、
  描边 1.75、圆角端点，覆盖导航 / 播放控制 / 操作 / 状态四类。
- **语义化设计 token**：`surface` / `fg` / `line` / `accent` 四级，
  层次靠亮度差而非描边堆叠；圆角收敛为 6 / 8 / 10 / 12 / 16 五档。
- **语义化组件类**：`.tc-row` `.tc-panel` `.tc-empty` `.tc-alert` `.tc-skeleton`
  `.tc-chip` `.tc-section-title`，列表行、空态、提示条不再各自手搓。
- **填充式进度条**：`--p` 变量驱动已播比例，替换原先的纯轨道样式。
- **骨架屏**：曲库首屏载入用骨架占位，替代原来的整块「载入中…」文字。

### 变更

- **全站 emoji 清零**：导航、播放控制、列表操作原先大量使用 emoji
  （♫ ▤ ◉ ⚙ ▶ 🔊 等），不同系统与浏览器字形、基线、颜色都不一致，
  是界面显得不专业的主要原因，全部替换为矢量图标。
- **导航改为单入口**：桌面只保留侧栏、移动端只保留底部 Tab，
  不再出现「抽屉 + 底部 Tab + 播放条」三重叠加。
- **主色收敛为单一强调色**，移除径向渐变背景、扫描线动画与满屏发光阴影。
- **播放条 / 上浮面板 / 全屏播放页**三处播放器统一视觉语言与图标。
- 循环模式图标改为从 `REPEAT_META` 单点取值，不再各组件各写一份。

### 修复

- 移除两个无任何路由引用的死视图（`Dashboard.vue` / `SearchView.vue`）。
