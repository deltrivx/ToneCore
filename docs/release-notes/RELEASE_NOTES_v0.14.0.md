# ToneCore v0.14.0

移除界面无用文案，修复音箱「设备为 0」的真实根因，并改为自主认证。

### 修复

- **登录密码未按契约哈希（致命）**：小米 `serviceLoginAuth2` 的 `hash` 参数要求
  **密码的 MD5 大写**，此前直接提交明文，稳定返回 code=70016「登录验证失败」，
  且与账号密码是否正确无关 —— 这是「自主登录一直失败」的直接原因。
  新增 `hashPassword()` 统一转换（已是 32 位十六进制则按已哈希处理，避免重复加密）。
- **鉴权失败被当成「没有设备」**：凭据过期时设备接口返回 401，旧逻辑静默返回
  空数组，界面显示 `devices:0`，看起来像音箱没连上，真实原因却是登录态过期。
  新增 `MinaAuthError`，`refreshDevices()` 捕获后单独上报 `authError`，
  界面显式提示「登录态已失效，请重新登录」，不再与「无设备」混淆。

### 变更

- **取消从 SongLoft 导入凭据**：删除 `songloft-import.ts` 及其调用，
  凭据只由用户在设置页登录小米账号取得。原注释称「自行登录易踩风控」，
  实测那条路走不通的真正原因是上述密码未哈希 —— 修掉后可直接自主登录。
- 移除界面中的冗余文案：登录页默认账号与环境变量说明、设置页的持久化说明、
  凭据保存路径提示、音箱配置区的来源标注等。

### 排查记录（设备为 0）

不是「没设备」。实测：用同一条代码路径换一份**未过期**凭据请求
`/admin/v2/device_list` 返回 200 且带回 1 台「小爱AI音箱(第二代)」；
而 ToneCore 存的凭据 `tokenExpiresAt` 为 2026-09-21，已过期。
加不加签名头结果一致（该接口不强制签名），故判定为凭据过期而非契约错误。
