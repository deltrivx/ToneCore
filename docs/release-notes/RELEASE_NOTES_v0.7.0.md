# ToneCore v0.7.0

## 变更

- **播放不再占用主页版面**：移除主页里硬塞的「正在播放」Hero，改为**底部常驻播放控制条**（封面/曲名/播放暂停/上下曲/进度/音量）；点击控制条**上浮**「正在播放」面板（大封面、完整控制、播放队列），**点面板外任意空白处自动收纳**，也可点「收纳」按钮手动收起。全屏歌词页保留为独立入口（⤢）。
- **主页回归本地歌曲**：默认展示本地音乐（专辑封面墙 + 曲目列表），点即播；歌单不再出现在主页。
- **歌单归曲库**：曲库页新增歌单区块（封面磁贴、新建、播放、删除），点开为详情浮层；曲目行保留「加入歌单」入口。
- **设置页重排**：去掉 `max-w-2xl`（宽屏右半边整片空白的根因），改为大屏两列栅格填满可用宽度。
- **新增「关于」区块**：版本号、音源数、曲目数、音乐目录/数据目录，以及仓库/更新日志/反馈入口。
