ToneCore 从「无头音乐中枢」升级为**自带完整播放器**：控制台改为侧边栏导航，
新增本地播放、歌词滚动与在线试听，并修掉一批评分、封面、歌词链路上的真实缺陷。

## 新增

- **内置播放器**：完整的播放队列（上一首 / 下一首 / 跳转 / 局部移除 / 清空）、
  暂停继续、进度拖动、音量调节，以及列表 / 单曲 / 随机三种循环模式。
  默认首页即「正在播放」，桌面端下方常驻迷你播放条，移动端可展开全屏播放页。
- **歌词**：LRCLIB 与网易云双源兜底，解析标准 LRC 时间轴并滚动高亮。
  纯音乐或取不到歌词时明确降级，不显示假数据。
- **在线试听与歌曲搜索**：搜索结果可直接试听、加入队列、落库，
  不必先去音箱点歌。
- **曲库封面**：扫描时抽取音频内嵌封面，落成独立小图缓存，
  列表与播放器直接展示，避免反复解析大体积音频文件。
- **控制台改版**：右上角配置入口改为**左侧侧边栏**（正在播放 / 曲库 / 音源 / 设置），
  桌面端常驻、移动端抽屉式，命名对齐主流音乐播放器习惯。
- **音源在线检测**：单个音源可一键实测能否取到直链，结果含耗时与失败原因。

## 修复

- **点错歌**：打分公式中「标题完全匹配」与「部分匹配」分差过小，
  版本噪音一叠加就会被翻唱反超。已拉开分值区间并加入平台质量权重，
  同时在分数过低时拒绝降级，宁可提示失败也不放错歌。
- **点播长时间卡住**：高分候选取链失败后会逐个串行重试并等满超时，
  实测单次失败耗时可达两分钟。已限制单候选取链时长。
- **音源检测全部超时**：检测走了洛雪不支持的搜索动作，
  导致每个音源都必然超时；已改为按真实能力检测取链。
- **封面与歌词大面积缺失**：原依赖的歌词服务已整体下线（接口返回 404），
  没有内嵌封面的歌曲永远补不上。已换用可达音源并增加多候选兜底。
- **内部封面抽取未生效**：抽取逻辑漏了异步等待，导致每首歌都被判定为「无封面」
  并写入占位标记、此后不再重试。已修正，且历史占位数据会自动重试补齐。
- **音源脚本可能拖垮宿主**：部分脚本在加载期抛出的异步异常会逃逸出原有捕获范围，
  影响同进程内其他脚本；已在沙箱内做异步异常隔离。

## 变更

- **下线失效平台**：咪咕接口改版后返回网页而非数据、酷狗存在证书校验失败，
  两者搜索结果恒为空，已从搜索平台与默认平台顺序中移除。
  接口响应会标注已下线平台，避免被误读成「搜索坏了」。
- **音源清理**：移除加载即失败的失效音源脚本（保留在 `_disabled` 目录便于恢复）。
- **图标换新**：改为亮色调，并提供矢量源文件便于后续调整。

## 升级提示

容器镜像与数据卷相互独立，直接更新镜像并重建容器即可，
已有曲库与配置不受影响。曲库封面会在下一次扫描时自动补齐。
