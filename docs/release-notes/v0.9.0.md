# ToneCore v0.9.0

## 修复

- **音源「停用」后卡片直接消失**（真 bug）：原实现把脚本文件**移出 `sources/` 目录**，而界面列表只扫该目录，于是停用即消失、且**无处可恢复**。改为**原地标记**：文件留在原处，文件名记入 `data/source-disabled.json`；界面照常列出（置灰、显示「已停用」），可一键重新启用；停用期间**不加载、不参与取链与下载**。历史遗留在 `_disabled/` 的脚本会自动迁回。
- **底部播放条不常驻**：此前队列一空整条消失、布局跳动。改为**始终常驻**，无播放时显示空态。
- **播放条不显示封面与歌词**：现显示专辑封面缩略图，第二行**滚动跟随当前歌词**；无歌词时退回显示专辑/音质。

## 变更

- **播放面板重做**（参照 Apple Music / Spotify 沉浸式设计）：封面取色模糊背景、大封面、白色圆形主播放键、可拖拽进度条、**滚动跟随的歌词区**、队列默认折叠；收纳交互保留。
- **WebUI 视觉基调升级**：卡片/按钮/输入框改为低不透明度白边框 + 柔和层次，圆角统一，进度条与滑块改白色主题。
- **小爱音箱配置补全**：新增**唤醒词**（回车添加、点标签删除）与**生效设备勾选**，并展示设备在线状态。
- 音源页新增「全部测试」；测试改为**逐平台执行**并落盘，**刷新后保留**。

## 优化

- **音源测试结果内联显示**：取消独立结果块，改在状态行显示「已加载 · 测试结果：正常 / 部分可用 / 不可用」+ 相对时间。
- **平台标签按结果着色**：正常绿、不通过红、未测试灰；停用整体置灰。平时也保持最近一次结果的着色。
