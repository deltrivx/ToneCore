# ToneCore v0.20.0

> 修复音源健康度死锁与歌词错配；全屏页支持左右滑切歌；新增入库下载进度面板。

## 修复一：音源「手动通过、自动 0%」的死锁

### 现象

音源卡片显示「不可用 · 0/2 成功 · 0%」，但手动点「测试」却提示「部分可用」。
两者严重不符。

### 根因（三个缺陷叠加）

| # | 缺陷 | 后果 |
|---|---|---|
| 1 | **两套账本**：自动记 `healthDetail`，手动记 `testResults` | 手动成功不计入成功率、不清熔断 |
| 2 | **饥饿选择**：`forPlatform()` 排序后 `.slice(0, maxParallel=3)`，<br>9 个源里后 6 个**永不被选中** | 永远刷不出成功记录 |
| 3 | **负分死锁**：`success === 0` 时仍用默认 `avgMs = 10000` | 得分 `0 - 100 = -100`，永久垫底 |

三者叠加成闭环：**因为没成功记录 → 排后面 → 从不被选中 → 更不可能有成功记录。**

现场数据印证：`星海音乐源.js` 手动 `ok=true`，但自动 `success=0 failure=2`。

### 修法

- 新增 `HealthTracker.recordProbe(name, ok, ms)`：手动测试成功即计一次成功
  **并清掉 `consecutiveFailures`**（脚本立刻从熔断放出，重新参与取链）；
  失败也计入，避免「测了跟没测一样」。
- `score()` 修正：`success === 0` 时**不扣延迟分**（没有延迟样本就不该罚），
  只返回 `rate * 100`，斩断负分死锁。

> 注：`consecutiveFailures` 此前还有一处 TRIP_COOLDOWN 自愈窗口，
> 本轮未改动（10 分钟冷却后探活，逻辑正确）。

## 修复二：歌词时间错乱

### 现象

播放时歌词与音频严重不匹配，时间轴错乱。

### 根因

`lyrics.ts` 的文件头注释写着「三种来源」，
但 **`readLocalLrc()` 只读同名 `.lrc`，第 2 条「音频内嵌歌词」从未实现**。

而刮削入库是把歌词写进 FLAC 标签的（日志 `lyrics: true`），
**音乐目录下并不会生成同名 `.lrc`** —— 实测 11 个 FLAC 只有 1 个 `.lrc`。

于是本地歌取歌词必然回落到在线接口；在线按歌名搜索，
经常命中翻唱或别的版本（尤其是有原声带/多个版本的歌），
时间轴自然与本地音频对不上。

实测 11 首本地歌只有 3 首带了内嵌歌词，其中一首还是
`[kuwo:064]` 开头的非标准格式 —— 这种文本塞进 `parseLrc` 会解析出错误时间轴。

### 修法

- 新增 `readEmbeddedLrc()`：经 `music-metadata` 读取 Vorbis / USLT 内嵌歌词；
- 优先级变为 **同名 .lrc > 内嵌标签 > 在线**；
- 新增 `looksLikeLrc()` 守卫：文本必须至少含一行标准 `[mm:ss.xx]` 时间标签
  才采用，否则宁可走在线也不要错词；
- `LyricResult.source` 增加 `'embedded'` 取值。

## 新增一：左右滑切歌

全屏播放页支持**左滑下一首 / 右滑上一首**，对齐主流音乐 App 手势。

两个必须避开的干扰源：

1. **横向 range 滑块**（进度条、音量）—— 它们自己要响应横向拖动，
   手势若吃掉横向位移，用户就没法拖进度了。判据：起点落在 input/range 上即不触发。
2. **歌词区纵向滚动** —— 要求横向位移 ≥ 60px 且 ≥ 纵向位移的 1.5 倍，
   避免斜着划被误判成切歌。

队列抽屉打开时不切歌（此时用户大概率在操作列表）。

## 新增二：入库 / 下载进度

`Downloader` 此前只有 `pending` / `size` 两个计数：点了「入库」之后
**完全没有可见反馈**，只能等曲库数量变化才知道结果，中途卡住也看不出来。
更尴尬的是 `api.downloads` 在前端有定义却**从未被调用过**。

现在：

- 后端增加任务级跟踪：任务 id、标题、已收/总字节、状态、失败原因；
  已结束任务按时间倒序保留最近 50 条，防止内存无界增长；
- **失败时必须落 `failed` 终态**，否则任务永远停在 running，进度条会一直转；
- `/api/downloads` 回传 `tasks` 与 `active`；
- 前端新增浮动进度面板，2.5s 轮询；服务端未返回 `Content-Length` 时
  百分比为 0，此时显示已下载字节数。
