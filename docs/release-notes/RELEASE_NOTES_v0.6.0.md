# ToneCore v0.6.0

## 修复

- **清理已删除文件残留的曲目**：在 ToneCore 之外用资源管理器删掉音频后，曲库索引不会同步，留下点不开的幽灵条目。新增 `GET /api/library/missing`（只读检查）与 `POST /api/library/prune`（清理）；清理时**同时删除歌单里的失效条目**并重算歌单封面，否则歌单会留下永远播不了的曲目。曲库页在有残留时显示黄色提示条与「清理失效曲目」按钮，扫描后自动复查。
- **音源健康度永久锁死（连坐）** —— 这正是「单脚本隔离测试能出直链、集成环境却恒为 0 成功」的原因，两处叠加：
  - `HealthTracker` 连续失败 ≥3 即熔断，而计数只有成功才清零；脚本被过滤后再没有调用机会，形成**永久锁死**。新增 10 分钟冷却窗口的**半开探活**，冷却后自动给一次重试机会。
  - `getUrl` 整体超时时对**整批脚本**记失败，一个慢脚本会拖垮同批其它脚本。改为只惩罚到点仍未应答的脚本，已报过成功/失败的不再重复挂账。

## 变更

- **主页按 Navidrome 视觉语言重做**，告别通用仪表盘卡片观感：
  - 「正在播放」改为大尺寸 Hero：封面 + 封面模糊着色背景 + 大字标题 + 控制条。
  - 「最近添加」由列表行改为**按歌手+专辑聚合的封面卡片墙**（悬停圆形播放按钮）。
  - 「歌单」改为封面磁贴网格，点击打开歌单详情浮层（曲目 / 播放 / 移出），不再就地展开。
  - 空态改为虚线占位卡，给出明确的下一步提示。

完整说明见 [CHANGELOG](https://github.com/deltrivx/ToneCore/blob/main/CHANGELOG.md)。
