# ToneCore v0.4.0

## 新增

- **播放页整合进音乐库**：原来「正在播放」是独立一页，听歌时要在「播放页 ↔ 曲库」之间来回切换，不符合 Navidrome / SongLoft 一类主流播放器的通行结构。现在曲库即主页面：右侧常驻「正在播放」面板（封面、进度、传输控制、播放队列），左侧点即播；全屏歌词与常驻迷你条继续承担沉浸式播放。桌面端为「列表 + 侧栏」双栏布局，窄屏自动降为单栏，由迷你条与全屏页接管。
- **统一搜索条**：曲库页原本只有一个「本地搜索」输入框，与顶栏全局搜索、在线搜索页三处并存，入口冗余。现收敛为一个搜索条，用「本地 / 在线」分段切换：本地过滤曲库，在线走 `/api/search` 联网搜歌并可直接试听、入队。在线搜索当前为**预留接入**，取链依赖音源健康度。

## 变更

- 移除已无引用的独立「正在播放」视图（其能力已并入曲库侧栏与全屏播放页）。
