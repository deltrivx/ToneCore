# ToneCore v0.5.0

参照 Navidrome / SongLoft 主流结构重做页面布局，并补齐歌单功能。

## 导航

收敛为四项：**主页 / 曲库 / 音源 / 设置**。「运行状态」折叠进侧栏底部状态条，「在线搜索」不再单独成页。

## 主页（默认落地页）

- 顶部**全网搜索**框：内联展示在线结果，可直接试听 / 入队，不跳页
- 右侧常驻**正在播放**面板：封面 / 进度 / 传输控制 / 播放队列
- **歌单**网格 + **最近添加**条（避免空态，新用户也能直接播放）

## 曲库

- 顶部**全网搜索**框与右上角独立的**本地搜索**小框分离，互不打扰
- 点开歌曲弹出**详情**（专辑 / 封面 / 时长 / 路径），可「重新刮削这首」（新增 `/api/scraper/song` 单首刮削）

## 歌单

新增命名的可持久化队列：主页展示歌单网格，曲库中可把任意本地歌曲「加入歌单」，整张歌单一键播放。
