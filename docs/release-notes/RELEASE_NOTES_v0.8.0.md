# ToneCore v0.8.0

## 新增

- **云端搜索三种检索维度**（`/api/search?type=song|artist|album`）：歌曲 / 歌手（取该歌手热门曲目）/ 专辑（取该专辑完整曲目）。平台适配：酷我 `ft`、网易云 `type=1|100|10`（歌手走 `artist/top/song`、专辑走 `album/{id}`）、QQ soso `t=0|2|3`（专辑走 `fcg_v8_album_info_cp`）。
- **在线结果直接入库**：单曲「入库」、按平台「全部入库」、以及「全部入库」；入库即下载落盘到本地曲库，进度实时汇报。
- **主页三种显示方式**：列表 / 小图 / 中图（选择持久化）。

## 变更

- 主页取消标题文案（不再显示「本地音乐」等标题）。
- 音源页取消历史健康度：不再显示成功率 / 熔断 / 「历史」标注，只保留加载状态与「本次测试」结果。
- 设置页取消「容器环境变量锁定」提示条。
