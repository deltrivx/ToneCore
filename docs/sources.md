# 音源管理

ToneCore 使用**洛雪音乐**格式的音源脚本（`.js`）。

## 放置位置

```
/data/sources/
├── 六音音源.js
├── 野花🌷.js
└── ...
```

放好后在「音源」页面点「重新加载」。

## 平台优先级

默认 `kw > kg > wy > mg > tx`，可在设置页调整。

酷我（kw）对无损 FLAC 支持最稳，建议保持第一。

## 音源可用性

音源脚本由社区维护，可能因上游风控失效。建议：

- 同时放 3~5 个音源，引擎会自动降级
- 定期检查「音源」页面的加载数量
- 失效的脚本直接删掉

## 安全提示

音源脚本是可执行 JS，**只放你信任的来源**。ToneCore 在沙箱中运行脚本，但仍建议审阅后再使用。
